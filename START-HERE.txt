GRIDFALL — ชุดพร้อมเล่นสำหรับ Windows 64-bit

เครื่องที่จะเปิดเกมต้องมี Edge หรือ Chrome
ชุดนี้รวม Node.js, ไฟล์เกม, เพลง และตัวเปิดลิงก์ออนไลน์ไว้แล้ว

เริ่มใช้งาน
1. แตก ZIP ทั้งหมดลงโฟลเดอร์บนเครื่องใหม่ เช่น D:\Games\GRIDFALL
   ให้เลือก Extract All / แยกไฟล์ทั้งหมด ก่อนเปิดเกม
2. เปิด INSTALL.cmd เพื่อตรวจว่าไฟล์ครบ แล้วปิดหน้าต่างตรวจไฟล์
3. เปิด PLAY.cmd เพื่อเล่น Solo หรือ LAN
   เบราว์เซอร์จะเปิดเกมให้ และหน้าต่างคำสั่งจะแสดงลิงก์ localhost / LAN

เล่นออนไลน์กับเพื่อนต่างเครือข่าย
1. เปิด ONLINE-FRESH.cmd
2. รอข้อความ GRIDFALL ONLINE READY หลังตรวจเว็บและ WebSocket ผ่านแล้ว
   เบราว์เซอร์จะเปิดลิงก์ https://…trycloudflare.com ให้
3. เปิดลิงก์นั้น เลือก Multiplayer ตั้งชื่อและเลือกตัวละคร แล้ว CREATE ROOM
4. กด COPY LINK ในห้องแล้วส่งลิงก์ให้เพื่อน
5. เพื่อนเปิดลิงก์ใน Edge หรือ Chrome แล้ว JOIN ROOM
   เพื่อนที่เป็นผู้เล่นอย่างเดียวใช้เบราว์เซอร์ได้เลย

เปิดหน้าต่าง PLAY / ONLINE-FRESH ค้างไว้ตลอดที่เล่น
กด Ctrl+C เพื่อปิดเซิร์ฟเวอร์ เมื่อเล่นจบ
ONLINE-FRESH จะเปิดโค้ดที่อยู่ในโฟลเดอร์นี้พร้อมเซิร์ฟเวอร์และลิงก์ใหม่ทุกครั้ง
ถ้าย้ายเกมไปอีกเครื่อง ให้ส่ง ZIP ทั้งชุด แล้วแตกใหม่ให้ครบ
ถ้ามีอัปเดตเกม ให้ใช้ ZIP ชุดใหม่ก่อนเปิด ONLINE-FRESH

เล่น LAN: เครื่องต้องอยู่บน Wi-Fi / LAN เดียวกัน ใช้ลิงก์ห้องที่ COPY LINK ให้
เล่นออนไลน์: เครื่องที่เปิด ONLINE-FRESH ต้องเชื่อมต่ออินเทอร์เน็ตและเปิดค้างไว้
ไฟล์อื่นในโฟลเดอร์ runtime, node_modules และ tools ต้องเก็บไว้คู่กับตัวเกม

ถ้าลิงก์ออนไลน์เปิดไม่ได้ ให้เปิด ONLINE-CHECK.cmd แล้วคัดลอกผลตรวจให้ผู้พัฒนา
